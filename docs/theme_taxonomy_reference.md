# 테마 Taxonomy 참고자료

이 문서는 네이버 테마 분류의 `normalized_name`/alias 후보를 정리하는 참고 큐다.
실제 구성종목 데이터는 `ThemeClassificationCollectorService`가 수집하는 네이버 금융 테마/업종 데이터에 귀속한다.

## 출처 경계

- StockEasy 종합 RS 화면(`https://stockeasy.intellio.kr/stock-analysis`)에서 관찰한 섹터/테마 명칭은 표시명·alias 후보로만 참고한다.
- StockEasy 자체를 자동 수집 원천이나 구성종목 truth source로 고정하지 않는다.
- alias 승격 전에는 네이버 원본 테마명, 현재 화면 표시명, 리포트 가독성을 함께 확인한다.
- 네이버에 같은 개념이 여러 raw 테마명으로 들어올 때만 `config/theme_aliases.yaml`에 추가한다.

## Alias 승격 기준

1. 네이버 원본 raw 테마명이 실제로 존재한다.
2. 서로 다른 raw 테마명이 같은 투자 개념을 가리킨다.
3. 합쳤을 때 구성종목이 과도하게 넓어지지 않는다.
4. 웹/텔레그램 리포트에서 표준명이 사용자가 바로 이해할 수 있는 이름이다.

## 적용 메모

- `로봇/자동화`는 현재 `config/theme_aliases.yaml`의 `로봇/피지컬AI`와 겹친다. 자동화·스마트팩토리를 같은 표준명으로 합칠지는 구성종목 폭을 보고 결정한다.
- `배터리셀`, `양극재`, `음극재/소재`는 모두 2차전지 하위 분류라 한 표준명으로 합치면 리포트 설명력이 떨어질 수 있다. 원본 테마가 충분히 나뉘면 하위 표준명을 유지한다.
- 업종 성격이 강한 후보는 네이버 업종(`category_type=industry`)과 중복될 수 있으므로 theme alias로 무리하게 넣지 않는다.
- 신규 alias를 추가할 때는 `tests/unit_test/services/test_theme_classification_collector_service.py`의 alias 동기화 계약을 유지한다.
